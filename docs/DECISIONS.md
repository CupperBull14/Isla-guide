# Журнал решений (ADR)

Формат: контекст → решение → последствия. Новые решения дописывать вниз, старые не удалять (если решение изменилось — новая запись, ссылающаяся на старую).

## ADR-001 — Только подтверждённые данные
Контекст: игровые числа легко перепутать (Legacy vs Evrima, устаревшие вики). Решение: числа и вердикты — только из источников; нет данных → `null`/«данных нет»; расхождения показываем, не скрываем. Последствия: матрица матчапов намеренно разрежена; нужен регулярный сбор данных.

## ADR-002 — Контент отдельно от компонентов
Решение: весь контент в `src/data/` (типизированные объекты), компоненты только рендерят. Последствия: обновление после патча = правка данных; `scripts/check.mjs` валидирует целостность.

## ADR-003 — Матчап — направленный
Решение: `A.matchups[opponent=B]` = оценка A против B; обратное не выводится. Последствия: для двусторонней пары нужны две записи; в UI везде формулировка «A → B».

## ADR-004 — Запрет AnimatePresence mode="wait" (баг «зависания»)
Контекст: при быстром переключении вкладок/кнопок содержимое не появлялось, помогал только F5; «Назад» иногда давал пустую страницу. Причина: переходы с выходной анимацией (`AnimatePresence mode="wait"|"popLayout"`, exit) могли застрять, особенно при вложенных `layoutId`. Решение: везде enter-only анимации; аккордеон без AnimatePresence; страницы — `lazyPage()` + `ErrorBoundary` (кнопка «Обновить» и авто-перезагрузка при устаревших чанках после деплоя). Защита: `npm run check` падает на `mode="wait"`.

## ADR-005 — Рост: таблицы = 1 нутриент, x1
Контекст: Rex 35 ч 33 мин казался нереальным; игрок: 12–15 ч. Решение: время в таблицах — базовое для одного нутриента; 2 нутриента ×2, 3 — ×3 (EQG, theisle.info 28.05.2026, подтверждено игроком). Заменяет прежнее решение В2 («+50%»). Открыто: Triceratops (EQG 29 ч 10 мин vs ≈12 ч theisle.info).

## ADR-006 — Кривые статов и Prime из таблиц EQG
Решение: `curve.normal/prime` из 6 точек; промежуточные значения — линейная оценка (помечается в UI). Где у Prime две цифры на три точки — 100% = 87,5% с ⚠️.

## ADR-007 — Источник «проверено в игре»
Решение: допускаются свидетельства опытного игрока (помощника проекта) как источник без URL, с датой; помечается отдельно, не смешивается с публикациями.

## ADR-008 — Деплой: статический сайт
Решение: GitHub Pages через Actions (`VITE_BASE=/<repo>/`), 404.html для SPA; Vercel/Netlify как альтернативы (`vercel.json`, `_redirects`). Перед сборкой в CI — `npm run check`.

## ADR-009 — Нет раздела «трофеи»
Решение В6: системы трофеев в Evrima нет в источниках. FAQ отвечает «данных нет».

## ADR-010 — Динозавры правятся вручную
Контекст: файлы были сгенерированы скриптом вне репозитория. Решение: с 2 окт 2026 генератор не используется; `src/data/dinosaurs/*.ts` — источник правды; целостность — `npm run check`.

## ADR-011 — Без подписей ИИ в коммитах
Решение владельца: в коммитах нет `Co-Authored-By`/`Claude-Session`.
